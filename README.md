1.Project Name - KeenKeeper
Live link-https://keen-keeper-07.netlify.app/

2.Project Description-
    KeenKeeper is a personal relationship management web application designed to help users track, manage, and nurture meaningful connections with their friends, family, and colleagues. Built with a modern, responsive, and clean user interface, it provides an intuitive dashboard to monitor how long it has been since the last contact, set interaction goals, and maintain a history of communications. It ensures you never lose touch with the people who matter most in your life.

3.Technologies Used-
    Frontend Library: React.js (Vite)

    Routing: React Router DOM

    Styling: Tailwind CSS (v4)

    Icons: Lucide React

    Data Visualization: Recharts (for Friendship Analytics Pie Chart)

    Notifications: React Hot Toast

    State Management: React Context API (for global interaction logging)

4.Key Features-
    Dynamic Friend Insights & Status Tracking: Displays real-time friend profiles using detailed cards in a responsive 4-column grid. Each card changes its background color dynamically based on the contact status (on-track, almost-due, or overdue) to instantly notify you who needs attention.

    Interactive Quick Check-In & Live Timeline: Allows users to log physical interactions (Calls, Texts, or Video Calls) directly from a friend's details page. These events automatically register globally via React Context, trigger beautiful toast notifications, and populate an interactive, historical log on the Timeline page.

    Advanced Timeline Filtering & Friendship Analytics: Features a challenge-ready filter system on the Timeline page to sort interaction history by specific types (Call/Text/Video). Additionally, the Stats page visualizes relationship data using an interactive Pie Chart to provide clear communication analytics.
